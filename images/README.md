# Folder Gambar Bento Grid 3x3 ("Kenangan Kita")

Folder ini digunakan untuk menyimpan foto-foto kenangan bersama **Komang Sinar Suriani Ayu Dalem Prabawaty** yang akan ditampilkan dalam format **Bento Grid 3x3** di halaman `yes.html`.

Secara default, halaman menggunakan foto ilustrasi estetis berkualitas tinggi. Anda bisa mengganti foto-foto tersebut dengan memasukkan foto asli Anda dengan penamaan `1.jpg` hingga `9.jpg` di folder ini!
