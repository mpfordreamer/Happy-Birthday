# Folder Musik

Tempatkan file lagu romantis Anda di folder ini dengan nama `song.mp3`.
Lagu akan langsung diputar secara otomatis (`auto putar`) ketika Komang Sinar Suriani Ayu Dalem Prabawaty mengklik tombol **Ya** dan masuk ke halaman perayaan (`yes.html`).

> Catatan: Jika file `song.mp3` belum dimasukkan, website telah dilengkapi dengan melodi romantis otomatis (Web Audio API) sehingga musik tetap mengalun indah!
